Status: verified locally

WEB-01 adds the first production frontend slice as a pinned React, TypeScript, and Vite workspace. Node `24.20.0` and pnpm `11.24.0` are exact toolchain authorities, the supported Node range begins at `24.15.0` to match the locked jsdom runtime, the Node declarations are pinned to `@types/node` `24.13.3`, and the frozen workspace lock is committed. Root Make targets expose every frontend gate and bootstrap the exact Chromium revision managed by pinned Playwright. The frontend CI job installs the frontend lock and runs static, unit, witness, and production-build verification; the browser job installs the Python and frontend locks plus Chromium before exercising the production browser/API boundary.

The page reads only `GET /api/v1/catalog/hierarchy` through one centralized same-origin client. The transport response begins as `unknown`; the WEB-01 normalizer validates every field it renders, rejects malformed types and unsupported enums, sorts each level only by numeric `displayOrder`, rejects duplicate IDs and display orders, reconciles projected department counts against the actual tree, and fails closed unless both projected and computed inventory are exactly five departments, twelve functions, thirty-six template identities, and forty-three instances. Source-evidence annotations remain intact in the API model; presentation removes only a terminal `; the source chart names <vendor>.` note from visible, title, and accessible card copy.

The visual scene follows ADR-0009 and the accepted desktop concept without a graph-library runtime. A pure layout function creates a fixed `1480 × 754` world, twelve fixed-width source-ordered function columns, computed department extents, vertically stacked fixed-size instance cards, and exactly forty-one horizontal or vertical SVG connector segments. Presentation fields such as purpose and enabled state do not enter the structural layout key. Every card retains its stable instance and template IDs; Community cards expose `Instance 1 of 2` and `Instance 2 of 2` in their accessible names and remain independently selectable.

Viewport algebra is separate from hierarchy geometry. First load and `Fit hierarchy` center the complete world with a bounded scale. Zoom buttons and wheel zoom preserve a screen anchor within `0.35..1.75`; pointer drag and arrow keys pan within a sixty-four-pixel overscan; zero restores fit; manual resize preserves the old world center; and selection applies only the smallest translation needed to reveal a card. All interactions operate on the existing scene and do not issue another hierarchy request.
