# WEB-06 verification

WEB-06 defines dedicated `/runs`, `/runs/:runId`, and `/artifacts/:artifactId` application routes over the authenticated API-07 read surface. Run detail shows the authoritative state, mode, selected instances, sealed plan and policies, step state and attempt limits, approvals, external actions, exposed receipt facts, and bounded artifact metadata. The timeline preserves persisted sequence order across server pages and treats a non-null cursor as incomplete history.

The run, timeline, and artifact clients accept only exact snake-case API-07 projections. Requested run, step, action, artifact, instance, and template identities must agree with their stable same-origin resource links. Pages are bounded, cursor-shaped, duplicate-free, and correctly ordered across cursor boundaries. Terminal run state/reason/transition facts, complete connector and WRITE-approval contracts, and every sealed step's selected template, configuration revision, routing slot, and capability must remain coherent. Artifact lineage and classification obey the same fail-closed rule. Unknown fields, unsafe object shapes, malformed timestamps and digests, cross-resource drift, expired metadata containing retained data, result metadata, and oversized recursively normalized JSON fail closed before rendering. Query keys carry only identifiers, filters, cursor, and limit—not payload, digest, metadata, receipt content, or any protected idempotency value.

Automatic interval polling refreshes the run, timeline, and artifact metadata only while the run is nonterminal, and all three queries explicitly disable interval refetching in background tabs. A read failure moves to a slower bounded interval. An authoritative `completed`, `failed`, `rejected`, or `cancelled` state stops automatic polling and triggers final timeline and artifact refreshes; manual refresh re-reads all three projections. The browser fixture begins with an executing run, follows a second keyset page, observes the terminal transition, verifies the final artifact-list read, and confirms that periodic run reads stop afterward. The dependency-free witness verifies that all three polling queries retain the background-interval opt-out.

Artifact list summaries remain metadata-only. Detail shows the server-redacted payload, keyed payload digest, schema identity and hash, classification, producer template and instance, source and parent lineage, configuration revision, and provider name/version/mode. Structured values and escaped syntax-highlighted JSON render through React text nodes. Rendering has explicit depth, node, and string caps, detects cycles, sparse arrays, accessors, and unsupported values without invoking them, and never infers Markdown from an arbitrary string.

Markdown is enabled only by a closed catalog template/schema presentation mapping. The restricted renderer does not parse raw HTML, never creates images or embeds, removes dangerous or ambiguous URLs, omits remote images, and permits only credential-free absolute HTTP(S) links with no-referrer isolation. The hostile browser fixture contains script, event-handler, remote-image, and `javascript:` payloads and verifies inert text, no executable DOM, no side effect, and zero non-loopback requests.

The surface uses the exact labels `Advisory — human decision required` for catalog-mapped advisory artifacts and `No real external delivery occurred` for authoritative mock-execution/provider facts. It reports the step's exposed idempotency-support value and an external action's exposed receipt identity, result status, and completion timestamp. API-07 does not expose an idempotency key, raw artifact/download representation, receipt-detail endpoint, or connector result metadata, so WEB-06 does not claim or link to any of them.

The focused unit gate selects every Vitest test carrying the `WEB-06` marker. The dependency-free witness imports the production run/artifact normalizers, query-key builders, timeline merge/polling model, trusted artifact-presentation mapping, bounded value preparer, and URL guard under pinned Node 24.20.0. The browser gate rebuilds the Vite application and exercises semantic headings/text, keyset timeline continuation, terminal polling, exposed support and receipt facts, keyboard artifact navigation, provenance, hostile Markdown, storage secrecy, and zero external requests.

The browser uses deterministic same-origin API fixtures because default local composition may contain no persisted WEB-06 run. It does not test live providers, connectors, workers, raw receipt storage, or production reverse proxies. WEB-07 retains narrow list/tree fallback; WEB-08 retains exhaustive accessibility, contrast, reduced-motion, and axe acceptance.
