Claim: **Acceptance target not yet verified** — this initial record defines the
source-bound quality journey and its evidence boundary. It does not record a
successful full aggregate, report audit or committed-feature gate.
Actual commands, source identities, environment and pass/fail/skip results must
be recorded after execution; no result is inferred from code or inventory review.

The required journey is the complete local aggregate behind `make verify`, run
through the AC-16 source-binding wrapper. It must not select backend-only mode,
filter gates, omit the browser phase or substitute fixture reports for an actual
observed run. The external tree-keyed record binds the result to its source; a
record for a different tree does not qualify this requirement.

The wrapper rejects interpreter, Make and test-loader overrides that could
bypass checks, then supplies child gates an explicit environment allowlist. It
retains the existing verifier's validated mock/safety selections, fresh coverage
path, offline/frozen settings and local dependency-cache path. Caller credentials
and unrelated configuration are not copied into child gates. This does not
provide an operating-system network boundary or authenticate tools on a hostile
host. Artifact reads are size-bounded regular-file reads; records reject duplicate
JSON keys, stale or changed artifacts, incomplete inventories and source drift.

A failed retry invalidates the prior successful tree-keyed record before tool
setup or gate execution. Audit accepts the original exact feature commit or an
identical-tree two-parent merge whose second parent is that feature; an arbitrary
same-tree commit is not sufficient. The external record resides under
`/tmp/marketing-agents-ac16/`; its referenced fresh coverage/report directory must
remain available for later audits. Losing those files requires another complete
run, not reconstructing a successful record from historical prose.
