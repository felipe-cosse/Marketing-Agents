## Limits

This requirement does not rerun application behavior tests cited by the guides.
Mechanical checks cannot prove arbitrary prose true, so independent source
review complements the curated significant-section contracts. The witness must
fail for stale/missing documentation distinctions, not a missing dependency.
External links and shell examples are inspected, never fetched or executed.

AC-15, AC-16 and final-source acceptance remain unverified. The separate AC-15
checkpoint and diagnostic branches are unchanged, and their failures are not
waived. No network/filter checks, Docker settings, application contracts or
protected evidence-policy/schema/verifier files change. CI stays paused. No
provider credentials, external delivery or PostgreSQL runtime are qualified.
